# GrowHelper Team for Hermes

> Долгий уход за растениями — в одном спокойном контуре: Telegram на входе, Hermes под капотом, понятный ответ на выходе.

GrowHelper — это team bundle для [Hermes Agent](https://github.com/NousResearch/hermes-agent), который превращает разрозненные сообщения, фотографии и измерения в последовательную историю конкретного растения.

Он не пытается быть «ещё одним умным чатом». У каждого Plant есть собственная Kanban-доска, рабочее пространство и память кампании — поэтому наблюдения не смешиваются, а рекомендации можно проверить задним числом.

## Что в нём цепляет

- **Plant-first память.** Отдельные `board + workspace` для каждого растения: campaign, baseline, current state, history, journal, фото и dataset живут рядом.
- **Команда вместо одного промпта.** Семь узких ролей работают по цепочке: наблюдение → состояние → гипотезы и действия → follow-up → независимая проверка → итог GrowHelper.
- **Evidence-first для фотографий.** Vision-профиль описывает только то, что видно; диагнозы и причинность появляются на следующих шагах, а не прячутся в одном уверенном ответе.
- **Долгий контекст без магии.** Kanban хранит реальный граф задач и handoff-ы, файлы Plant — долговременную историю, Telegram — точный публичный диалог.
- **Dashboard, который показывает работу.** Отдельная вкладка GrowHelper собирает Plants, активные Cycles, статусы, retries, ошибки, handoff metadata, фото и историю — при этом штатный Hermes Dashboard остаётся доступен.
- **Telegram без двойных сообщений.** Idempotency защищает от повторов, на Plant допускается один активный Cycle, а неясный timeout доставки блокируется до ручной проверки.
- **Native для Hermes.** Profiles, один plugin, hooks, Kanban и Dashboard plugin — без форка Hermes и без отдельного backend-сервиса.

## Как проходит один запрос

```text
Telegram: текст или фото
          ↓
GrowHelper определяет Plant и запускает Cycle
          ↓
specialists возвращают короткие проверяемые handoff-ы
          ↓
GrowHelper собирает наблюдения, выводы и рекомендации
          ↓
один идемпотентный ответ в Telegram
```

На выходе получается не просто совет, а аккуратное разделение:

```text
observation  →  inference  →  recommendation  →  follow-up
```

Проект задуман как практичный слой над Hermes: достаточно лёгкий, чтобы оставаться KISS, и достаточно строгий, чтобы история выращивания не превращалась в ленту догадок.
