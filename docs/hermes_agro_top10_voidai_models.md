## Рекомендации для Hermes Agro Profiles

В Hermes Agro предусмотрены 7 постоянных Profiles: `agro-orchestrator`, `vision-observation`, `plant-state`, `cultivation-advisor`, `task-followup`, `data-curator`, `reviewer`. Orchestrator должен быть hub, а не предметным специалистом; специалисты вызываются только когда релевантны текущему событию.

| Hermes Profile | Рекомендуемая модель | Reasoning | Почему |
|---|---|---|---|
| **`agro-orchestrator`** | **Claude Sonnet 5** | medium; high для сложного synthesis | Лучший баланс между tool use, выполнением протокола, маршрутизацией задач и качеством synthesis. Не должен самостоятельно подменять агрономов. |
| **`vision-observation`** | **Gemini 3.6 Flash** | medium | Наиболее рациональный вариант для анализа фото. Роль должна описывать видимые признаки и ограничения изображения, а не ставить окончательный диагноз. |
| **`plant-state`** | **DeepSeek V4 Flash-0731** | medium/high | Хорошо подходит для анализа динамики pH/EC/температуры, изменений состояния, противоречивых наблюдений и missing data. |
| **`cultivation-advisor`** | **DeepSeek V4 Pro** | high | Основной агрономический reasoning: причины, гипотезы, evidence for/against, стратегия выращивания и последовательность действий. |
| **`task-followup`** | **GPT-5.4 Mini** | low/medium | Дёшево и достаточно надёжно превращает synthesis в конкретные действия: что сделать, измерить, сфотографировать и когда проверить. |
| **`data-curator`** | **Claude Haiku 4.5** | low | Хорош для отбора reusable evidence, классификации данных и аккуратного формирования dataset без оплаты за Sonnet-класс модели. |
| **`reviewer`** | **Kimi K3** | high | Фронтирный независимый reviewer другого семейства. Вызывать только при противоречиях, важных решениях или крупной смене стратегии. |

## Временный `general` subagent

**Основной выбор: `GPT-5.6 Luna`.**

Использовать только когда постоянному specialist действительно нужен анализ вне своей непосредственной компетенции. Это соответствует Hermes-подходу: временный `general` не входит в постоянный roster и вызывается максимум один раз из specialist-задачи.

Если задача требует внешнего исследования и свежих источников, отдельно можно рассмотреть `sonar-deep-research`, но не как обычного постоянного specialist.

## Практический production-набор

```text
agro-orchestrator    → claude-sonnet-5
vision-observation   → gemini-3.6-flash
plant-state          → deepseek-v4-flash-0731
cultivation-advisor  → deepseek-v4-pro
task-followup        → gpt-5.4-mini
data-curator         → claude-haiku-4-5
reviewer             → kimi-k3

temporary general    → gpt-5.6-luna
```

Такой набор оставляет дорогие frontier-вызовы только там, где они действительно дают пользу: сложный synthesis, агрономическая стратегия и независимый review. Для механических и регулярных операций используются заметно более дешёвые модели.
